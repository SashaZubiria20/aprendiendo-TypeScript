# Aprendiendo TypeScript

Este repositorio contiene los ejercicios y prácticas realizados durante mi formación inicial en **TypeScript**. El objetivo fue dominar desde los conceptos básicos de tipado hasta la integración con el DOM y manipulación de APIs.

## Estructura del Proyecto
El código está organizado por bloques temáticos. Cada archivo en `src/` representa un concepto aprendido:
- `tiposDeDatos.ts`: Tipos primitivos, inferencia y tipado explícito.
- `tiposDeDatosAvanzados.ts`: Aliases, Uniones, Intersecciones y Tipos Literales.
- `funciones.ts`: Parámetros, retornos y tipo `void`.
- `dom.ts`: Manipulación de elementos y aserción de tipos (`as`).
- `herencia.ts`: Programación Orientada a Objetos, clases y herencia.
- `interfaces.ts` / `interfacesEnClases.ts`: Contratos de objetos.
- `eventos.ts`: Reactividad y eventos del DOM.
- `fetch.ts`: Consumo de APIs mediante Async/Await.

## Cómo probar los ejercicios
Para ver los ejercicios en funcionamiento:
1. Abrí el archivo `src/main.ts`.
2. **Descomentá** únicamente la línea `import` del bloque que desees probar.
3. Asegurate de que el servidor de desarrollo esté corriendo (`npm run dev`).
4. Observá el resultado en la consola del navegador y en la interfaz.
